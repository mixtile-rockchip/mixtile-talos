## Summary

Talos Linux v1.14.2 (kernel 6.18.54-talos) for the **Mixtile Blade 3**
(RK3588) with **openmiop** built in: Ethernet (`omi0`) between the blades of
a Mixtile Cluster Box over its PCIe switch. Nothing has to be compiled.

**v0.4.0-rc.1** is the Blade OS of OpenMIOP Stack v0.4.0-rc.1. Kernel,
DTB, U-Boot and the other extensions are the same as in v0.3.0; only
openmiop changes:

* **Gateway pull: LAN and internet to the blade ~1.5x faster.** The
  Cluster Box BMC used to write every frame for a blade into the blade's
  PCIe BAR with its CPU, one 32-bit write per word (~90 Mbit/s, BMC CPU
  at 99 %). With ClusterBox firmware v0.2.0-rc.1 the blade reads the
  frame from BMC memory with an eDMA read channel. Negotiated per blade:
  this release works with older BMC firmware (old path), and older
  blades work with the new firmware.

Built by [GitHub Actions](@RUN_URL@) from commit `@COMMIT@`.
Changes: [CHANGELOG.md](https://github.com/roysbike/mixtile-talos/blob/v0.4.0-rc.1/CHANGELOG.md).

Inside the image: Talos v1.14.2, kernel 6.18.54-talos, the v0.3.0 DTB and
U-Boot 2026.07, and the extensions openmiop 0.4.0-rc.1 (pcie-ep-net
`@OPENMIOP_REF@`; also `blade3-nvme-recover` and `blade3-leds`), drbd,
zfs, iscsi-tools, panfrost, rockchip-rknn. `module.sig_enforce` is off
(the openmiop module is unsigned). Image references: extension
`@EXTENSION@`, overlay `@OVERLAY@`. Kubernetes is not pinned by the image
(tested with v1.34.3).

## Supported hardware

Mixtile Blade 3 (RK3588), standalone or in a Mixtile Cluster Box. Gateway
pull needs the BMC's `omi-rc` from pcie-ep-net v0.4.0-rc.1:
[ClusterBox firmware v0.2.0-rc.1](https://github.com/roysbike/mixtile-clusterbox-mt7620a-openwrt/releases/tag/v0.2.0-rc.1).
Blades and BMC can be updated in either order.

## Install a new node

As in [v0.3.0](https://github.com/roysbike/mixtile-talos/releases/tag/v0.3.0#install-a-new-node),
with this release's image and `machine.install.image: @INSTALLER@`. The
serial console must show `enabling system extension openmiop 0.4.0-rc.1-v1.14.2`.

## Upgrade an existing node

One node at a time; mind etcd quorum; wait until DRBD and the databases
are healthy again before the next node.

```sh
talosctl -n <node> upgrade --image @INSTALLER@
```

* Keep the default drain. A roll with `--drain=false` left DRBD replicas
  of a running database in different states and corrupted its ext4
  (2026-10-12, Cozystack on DRBD 9.3.4).
* Always pass `--image` and keep `machine.install.image` in the machine
  configuration equal to it; do not set
  `machine.install.grubUseUKICmdline: false`.
* Same machine configuration as v0.3.0. Rollback:
  `talosctl -n <node> rollback`.

## Verification

```sh
talosctl -n <node> get extensions              # openmiop 0.4.0-rc.1-v1.14.2
talosctl -n <node> dmesg | grep openmiop       # "peer M up, 4 queues, doorbell"
talosctl -n <node> get links | grep omi0       # alias omi0 on enx<mac>, up
# on the BMC with firmware v0.2.0-rc.1:
dmesg | grep omi0                              # "node N active: ..., gateway pull"
```

## Tested

Lab Cluster Box, 2026-10-13: the same driver source (test image
ci-48-0269dbaa, openmiop 0.4.0-dev.1) on .108, the other three blades on
v0.3.0, BMC on firmware v0.1.1 with the v0.4.0-rc.1 `omi-rc` code loaded
by hand. This release build is inspected in CI
(`scripts/verify-installer.sh`).

| Test | .108 (gateway pull) | .133 (v0.3.0) |
| --- | --- | --- |
| LAN -> blade through the BMC | 141-145 Mbit/s | 92-95 Mbit/s |
| Internet -> blade | 152-155 Mbit/s | 97-106 Mbit/s |
| BMC -> blade, no NAT | 204 Mbit/s | 130 Mbit/s |
| Blade -> LAN | 264-272 Mbit/s | 267-276 Mbit/s |

444 158 frames pulled, 0 pull errors. Upgrade with drain, P2P to the
v0.3.0 blades (4 queues, doorbell) and the NVMe were fine.

## Known limitations

* Only one blade ran the new driver at tag time; the roll to all four
  comes before v0.4.0.
* The BMC CPU is now the gateway limit (~140-150 Mbit/s to a blade).
* As in v0.3.0: one TCP flow uses one queue (~4.7 Gbit/s); a BMC reboot
  resets every blade link for the length of its boot.
